13 · Field Manual

The book

32 institutional tools in the Cyphr scanner — what they mean.

Order Flow (8)

  • CVD — Cumulative Volume Delta. Sum of buy − sell volume. Divergence = exhaustion.
  • OBI — Orderbook Imbalance, top-20 bid/ask depth ratio. >1.5 bullish absorption, <0.67 bearish.
  • DOM Walls — Single levels >3× surrounding average. Magnets.
  • Funding — Binance perp 8h funding rate. Extremes = crowded trade.
  • OI Δ — 24h Open Interest change. Up+OI rising = real trend; up+OI falling = short cover.
  • L/S Ratio — Retail long/short positioning. Contrarian fade extremes.
  • Taker Ratio — Aggressive buyer/seller. Persistent >1.2 sustained pressure.
  • Whale Tape — aggTrade WS >$100k institutional prints.

Price/Vol Action (6)

  • VWAP slope + distance — Above & rising = institutional accumulation.
  • Volume Profile — POC / VAH / VAL = highest-volume + 70% value area edges.
  • MTF Bias — VWAP slope alignment across 15m/1h/4h/1d/1w.
  • Hurst Exponent — H>0.5 trending, H<0.5 mean-reverting, H≈0.5 random walk.
  • Z-Score — Standard deviations from rolling mean. |Z|>2 extreme.
  • Kalman Filter — Denoised trend extraction. Smoother than EMA, no lag.

Volatility + Microstructure (5)

  • GARCH(1,1) — Vol forecast accounting for clustering. Predicts next-bar σ.
  • VPIN — Volume-synchronized Probability of Informed Trading. Pre-flash-crash flow toxicity (Easley/López de Prado).
  • Kyle's λ — Market impact per unit volume. Higher = thinner book.
  • Amihud Illiquidity — |return|/volume ratio. Liquidity premium.
  • Roll Spread — Implied bid-ask from price autocovariance.

Structure + Regime (3)

  • Smart Money BOS/CHoCH — Break of Structure / Change of Character detection.
  • Wyckoff Phase — Accumulation/Markup/Distribution/Markdown classifier.
  • Beta-to-BTC — Rolling 30-bar regression coefficient. Risk-on/off filter.

Extended Quant Pack (12)

  • OFI — Order Flow Imbalance, top-5 signed depth pressure.
  • Microprice — size-weighted fair value tilt vs mid (Gatheral).
  • Roll Spread — implied bid-ask from price autocovariance.
  • Choppiness — range vs ATR; >61.8 = chop (penalised), <38.2 = trend.
  • Sortino — return per unit downside deviation.
  • Information Ratio vs BTC — active return / tracking error.
  • Lee-Mykland Jump — standardised return vs local bipower vol; flags jumps.
  • Bipower Variation — jump-robust realised volatility.
  • ρ vs BTC — Pearson correlation of returns (regime coupling).
  • Spectral Cycle — dominant cycle length via autocorrelation peak.
  • Trade Intensity Z — z-score of current volume vs rolling.
  • Hawkes Intensity — self-exciting activity clustering λ.

Edge Layer (v23)

  • Gann Confluence — SQ9 rings + Golden ladder + octave levels computed per symbol; score is boosted when price hugs a level (<1.5%).
  • Walk-forward Edge — momentum-persistence hit-rate measured on the coin’s own recent history.
  • MTF Matrix — 15m/1h/4h/1d slope agreement (in the signal panel).
  • Liquidation Heat — forced-order intensity across rolling 30-min buckets.

Reading a signal

Each signal: grade (S/A/B/C), direction, composite score (0–99 from z-sum of 32 tools), type (SCALP/INTRADAY/DAYTRADE/SWING/POSITION from ATR%+MTF), entry/SL/TP1/TP2/TP3 (ATR-based), and full confluence breakdown.
